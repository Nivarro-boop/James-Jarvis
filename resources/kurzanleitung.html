Void James

Ein Assistent, mit dem man spricht. Diese Seite reicht für den Anfang.

1. Beim allerersten Öffnen meldet sich Windows

Es erscheint ein blaues Fenster: „Der Computer wurde durch Windows geschützt". Das ist kein Virus und kein Fehler — Windows sagt das bei jedem Programm, für das kein Zertifikat gekauft wurde. So geht es weiter:

  1. Auf Weitere Informationen klicken (kleiner Text in der Mitte).
  2. Dann auf Trotzdem ausführen.

Das passiert nur einmal, bei der Installation.

2. So sprichst du mit ihm

Auf dem Bildschirm schwebt eine kleine leuchtende Kugel. Es gibt drei Wege:

  • „Hey James" laut sagen. Er wartet ständig auf diese zwei Wörter — das geschieht auf diesem Rechner und wird nirgendwo hingeschickt. Erst danach hört er richtig zu.
  • Alt + Leertaste drücken. Funktioniert auch, wenn ein anderes Programm im Vordergrund ist.
  • Die Kugel anklicken.

Danach einfach reden, ganz normal, in ganzen Sätzen. Er antwortet laut. Du darfst ihn dabei jederzeit unterbrechen — einfach weiterreden, er hört auf.

3. So bringst du ihn zum Schweigen

Dreimal Esc drücken — das ist der Not-Aus. Er hört sofort auf, egal womit er gerade beschäftigt ist. Esc ist die Taste ganz links oben auf der Tastatur.

  • Die Kugel anklicken, während er redet: Er wird still.
  • Ruhe für längere Zeit: Rechtsklick auf das kleine James-Symbol unten rechts neben der Uhr → James stilllegen. Dort geht er auch wieder an.
  • Ganz beenden: dasselbe Menü → Beenden.

4. Was du ihn fragen kannst

  • „Wie wird das Wetter morgen?"
  • „Was habe ich diese Woche für Termine?" — wenn der Kalender verbunden ist.
  • „Lies mir meine neuen E-Mails vor." — wenn Gmail verbunden ist.
  • „Stell einen Wecker auf zwanzig nach drei."
  • „Mach mir YouTube auf." / „Such mir, wann der Baumarkt zusperrt."
  • „Ruf die Anna an." — er fragt vorher nach, bevor er wirklich wählt.

Wenn er etwas nicht kann, sagt er das. Er tut nicht so, als hätte er es erledigt.

5. Was er von sich aus nie tut

  • Etwas kaufen oder eine Bestellung abschicken.
  • Ein Passwort, eine Kontonummer oder Kartendaten eintippen.
  • In einem Bank- oder Bezahlfenster irgendetwas anklicken.

Vor allem, was sich nicht zurücknehmen lässt — eine Mail verschicken, einen Termin absagen, etwas löschen, jemanden anrufen — fragt er vorher laut nach und wartet auf ein Ja.

6. Wenn etwas nicht funktioniert

  1. Zahnrad oben im Fenster anklicken (oder Rechtsklick auf das Symbol neben der Uhr).
  2. Links unten auf Über.
  3. Auf Protokoll zeigen klicken. Es öffnet sich ein Ordner mit einer Datei namens jarvis.log.
  4. Diese Datei an denjenigen schicken, der dir James eingerichtet hat.

In der Datei steht, was zuletzt schiefgegangen ist. Zugangsschlüssel und Passwörter werden darin automatisch unkenntlich gemacht.

Er hört mich nicht? Meistens ist das falsche Mikrofon eingestellt. Im Einstellungsfenster unter Über → Einrichtung erneut durchgehen gibt es einen Balken, der sich bewegen muss, wenn du sprichst.

Void James läuft auf diesem Rechner. Gesprochenes geht zur Verarbeitung an Google und wird nicht dauerhaft gespeichert. Das Zuhören auf „Hey James" bleibt hier.
